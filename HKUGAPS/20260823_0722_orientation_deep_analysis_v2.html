3.1 學業與評估（21f + 簡報）

  • 小一小二冇考試：只有進展性評估（Formative Assessment）；小三至小六先有總結性評估（小六三次）
  • FA 形式：默書、文法/數學小測、表演評估（跳舞/唱歌）、說話任務、口頭匯報、專題簡報；需通知嘅 FA 提前至少 3 個上課日通知（簡報新增）
  • 等級制：A 優異 88-100｜B 良好 75-87｜C 尚可 60-74｜D 仍需改善 ≤59
  • 升班準則：總成績全科 C 或以上 + 中英數 C 或以上 + 操行 B 或以上
  • 三學期制：每學期有「學習成果展示會談日」（家長見老師）；學生表現報告學年完結先發還
  • 課程結構：上午 KLA 學科（每節 45 分鐘）+ D.E.A.R. 早讀時段；下午 60 分鐘單元課（Module）+ ELA 延伸活動（多達 60 項，周五時段+放學後+周六）
  • 一年級學 12-15 個單元課程；中文科普通話授課；科學科部分英語授課
  • 音樂課程（簡報新增）：Module 音樂 P1=中國鼓樂（Charlotte 今年學）；P2 非洲鼓、P3 手鐘、P4 GarageBand 編曲、P5 粵劇、P6 創作；另有樂器班+音樂團隊（合唱團/弦樂團/管樂團/敲擊樂團，要試音）

3.2 家課政策（21f + 21g + 簡報）

  • 功課量上限：P1-2 每日 ≤1 小時（每科 0-15 分鐘；P3-4 ≤1.5hr；P5-6 ≤2hr）— 簡報詳列表
  • 欠交階梯（簡報版）：勤學室 Rm 205 補做+手冊記錄 → 第 3 次家校通訊 → 第 4 次警告信 → 第 5 次起留校完成（21f 版第 4 次先發通知書 — 見第六節出入位）
  • 21g 功課記錄冊（每學期一本，共三本）：每日格式 = 日期 + 體溫 + 中/英/數/其他功課 + 家長簽署；欠交要簽 P.45 欠交表
  • 每日自查五問（簡報新增）：抄齊手冊？做齊家課？檢查齊？放入家課袋？家課袋入書包？— 孩子自查表形式
  • 家長角色（簡報金句）：「家長可檢視功課，但不用告訴孩子，以培養寫手冊嘅自理及時間管理能力」
  • 家課袋文化：功課放入「家課袋」；每日執書包；校務處唔代交漏帶物品；放學後唔可以返課室攞嘢
  • eClass「學生手冊」頁每日上載各班家課表可核對
  • 功課親子策略（簡報 Dos）：營造支援環境、具體針對性讚賞、按專注力調節時長、「Me Time」做獎勵
